# Workshop Portfolio + Gemini Guide

Open `index.html` in a browser. No packages, Node.js, or server are needed.

To make the guide answer questions, open `script.js` and replace `PASTE_YOUR_KEY_HERE` with a Gemini API key. Update `portfolioFacts` to describe the student's own work.

This direct browser-key approach is only suitable for a temporary local workshop demo. Remove the key before publishing the site or uploading it to GitHub.

Replace `headshot.svg` with the student's own image when they are ready.
